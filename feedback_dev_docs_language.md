Documentation aimed at developers/contributors in this repo should be written in English so other developers can understand it.

**Why:** The user explicitly asked to translate the Spanish external/README.md into English "para que los desarrolladores lo puedan entender".

**How to apply:** When writing or updating docs meant for contributors/developers (READMEs, investigation notes, agent instructions), default to English. App UI/strings may follow their own convention, but repo-level dev docs => English.
